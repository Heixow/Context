# 视觉系统：科幻仪器 / Orbital Console

> 版本：M0 锁定 · 2026-11-26
> 适用：渲染层所有界面（不可用于对外营销页）
> 样稿：`docs/design/mockups/scifi-dark.png`、`scifi-light.png`

## 1. 方向

以航天/科研仪器的控制台为参照：深空中性底、细网格、等宽遥测标签、克制的琥珀信号光。强调「可读的科幻」，而不是霓虹赛博。信息密度高，但正文保持常规阅读节奏。

设计转盘：

| 转盘             | 值  | 说明                               |
| ---------------- | --- | ---------------------------------- |
| DESIGN_VARIANCE  | 4   | 工具型产品，结构稳定，局部不对称   |
| MOTION_INTENSITY | 3   | 只用 hover / active / 状态过渡     |
| VISUAL_DENSITY   | 8   | 驾驶舱密度，元数据紧凑，正文不限缩 |

## 2. 色彩

单一信号色：琥珀。红色仅用于「丢弃 / 错误」。其余靠中性色与发丝线建立层级。

| 角色        | Token        | 亮色                  | 暗色                     |
| ----------- | ------------ | --------------------- | ------------------------ |
| 画布        | `--bg`       | `#e9eff4`             | `#06080b`                |
| 面板        | `--panel`    | `#f5f8fb`             | `#0b0f15`                |
| 次级面板    | `--panel-2`  | `#edf2f6`             | `#0e141c`                |
| 正文        | `--ink`      | `#0b1520`             | `#e8f0f7`                |
| 次级文字    | `--muted`    | `#5a6b7b`             | `#8595a6`                |
| 结构线      | `--line`     | `rgba(30,70,100,.16)` | `rgba(120,170,200,.16)`  |
| 信号        | `--accent`   | `#b45309`             | `#f5b94c`                |
| 丢弃 / 错误 | `--drop-ink` | `#a32020`             | `#ff8a8a`                |
| 网格        | `--grid`     | `rgba(30,70,100,.06)` | `rgba(120,170,200,.055)` |
| 辉光        | `--glow`     | `rgba(180,83,9,.08)`  | `rgba(245,185,76,.1)`    |

规则：

- 不用纯黑或纯白；不用紫蓝霓虹渐变。
- 每屏最多一个强调色；红色只承担语义告警。
- 辉光只允许出现在：状态点、进度条、环形仪表、激活标签下划线、标题角标。
- 同一屏辉光元素不超过 3 处（不含扫描线）。

## 3. 字体

| 用途        | 字体                              | 规格                          |
| ----------- | --------------------------------- | ----------------------------- |
| UI / 正文   | `Geist Variable`                  | 13px / 1.65；长文本 78ch 限宽 |
| 遥测 / 数字 | `Geist Mono Variable`             | 9.5–11.5px，`tabular-nums`    |
| 中文回退    | `Microsoft YaHei` / `PingFang SC` | 与 Geist 混排时保持 1.65 行高 |

字阶：`9.5 / 10.5 / 11.5 / 13 / 15 / 17 / 24 / 26px`，全部定义在 `tokens.css`。
禁止 Inter；禁止在数据界面使用衬线体；数字一律等宽。

## 4. 间距、圆角、层级

- 间距基准 4px：`4 / 8 / 12 / 16 / 20 / 24`。
- 圆角：`--radius: 4px`，`--radius-sm: 2px`；不允许大圆角与胶囊化数据面板。
- 结构优先用 1px 发丝线，不用阴影表达层级。
- z-index：sticky 10、扫描线 40、覆盖层 100；禁止随手使用 9999。

## 5. 布局

```
┌ titlebar 52 ┐
├ telemetry 26 ┤
│ 240 | 1fr | 280–320 │
├ composer ────┤
└ statusbar 32 ┘
```

- 左栏：会话与帧列表；右栏：概览 / SYSTEM / TOOLS。
- 宽度低于 1180px 时左栏收至 220px、右栏 270px，并隐藏面包屑。
- 主栏与右栏保留四角定位标；扫描线覆盖全屏但 `pointer-events: none`。
- 时间线、侧栏、检查器各自滚动，页面本身不滚动。

## 6. 组件规范

| 组件     | 规范                                             |
| -------- | ------------------------------------------------ |
| 标题栏   | 52px；底部 1px 琥珀渐变线；菱形标记              |
| 遥测条   | 26px；等宽大写；数值分组用 1px 分隔              |
| 会话项   | 1px 边框；选中项琥珀描边 + 极淡内发光            |
| 帧头     | 标题 + 元数据 + 精确 token 数 + token 波形       |
| 消息卡   | 不套卡片；`border-bottom` 分隔；角色标签带 `[ ]` |
| 工具块   | 1px 边框，头部等宽标签，代码区最大 120px 可滚动  |
| 丢弃态   | 整体 55% 不透明度 + 删除线 + 红色标签            |
| 环形仪表 | 86px；外圈刻度环；中心百分比用等宽字             |
| 按钮     | 主按钮琥珀填充；次按钮描边；幽灵按钮仅文字       |
| 输入框   | 标签在上；错误态红色边框 + 下方错误文案          |

## 7. 状态矩阵（每个交互组件必须齐全）

`default / hover / active / focus-visible / disabled / loading / empty / error`

- loading 使用与布局同形状的骨架，不用旋转圆圈。
- empty 给出下一步动作，不只写「暂无数据」。
- error 就近展示，给出可执行动作。
- focus-visible 统一 1px 琥珀轮廓，offset 2px。
- 骨架微光与所有过渡在 `prefers-reduced-motion` 下关闭。

## 8. 动效

- 时长：`120ms`（反馈）/ `200ms`（状态切换）。
- 曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 只动画 `transform` 与 `opacity`；不动画宽高与位置。
- 扫描线与网格是静态纹理，不参与动画。
- 不做滚动叙事、视差、鼠标跟随。

## 9. 可访问性

- 正文对比度 ≥ 4.5:1；大字与图形 ≥ 3:1。
- 键盘可达：所有按钮可 Tab，焦点环可见；输入框有 `aria-label`。
- 颜色不是唯一信号：丢弃态同时有删除线与文字标签。
- 桌面点击目标最小 32×32；移动/窄窗 44×44（后续阶段）。
- 图标不单独承担语义，必须有文字或 `aria-label`。

## 10. 禁用清单

- Inter、Roboto、Arial 作为 UI 字体。
- 纯黑 `#000000`、纯白大面积背景。
- 紫蓝渐变、霓虹外发光、玻璃拟态堆叠。
- 三列等宽卡片、居中大标题营销结构。
- emoji、Lorem Ipsum、「John Doe / Acme」类占位内容。
- 装饰性图标雨、无意义 HUD 噪声、超过预算的发光。

## 11. 实现约定

- 唯一色彩来源：`src/styles/tokens.css`；组件内不写硬编码颜色。
- 布局与组件样式：`src/styles/app.css`；新增组件必须复用现有 token。
- HUD 装饰全部由 CSS/SVG 生成，不引入位图资源。
- 字体自托管：`@fontsource-variable/geist` 与 `@fontsource-variable/geist-mono`。
- 组件图鉴：应用内 `?view=kit`，覆盖色彩、字体、控件、消息块、数据与状态。
- Mock 数据：`src/mocks/frame.ts`；M0 后由 C 的共享契约替换。
